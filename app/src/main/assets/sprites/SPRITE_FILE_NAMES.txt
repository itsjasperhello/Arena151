ARENA 151 - SPRITE FILE NAMES
=============================
Put animated GIFs in this folder, named exactly as below (lowercase).
In the Android project this folder is app/src/main/assets/sprites.

  Front sprite:  <name>.gif       faces LEFT  (toward the viewer)
  Back sprite:   <name> (1).gif   faces RIGHT (away from the viewer)

The game mirrors both so each Pokemon faces where it is heading, shows the back sprite while it
moves up the screen (away from the camera) and the front sprite otherwise. Every GIF frame plays
with its own timing. Sizes can differ per Pokemon; each sprite is anchored by its feet.
No back sprite? The front one is used for both. No GIF? A PNG with the same name is used,
and anything missing falls back to the built-in generated art.
